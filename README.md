# PlayAuto

用于连接 AutoPlay 车载盒子的 Android 应用，提供 CarPlay 投屏、音频播放和触控操作。

- 最低系统：Android 4.4（API 19）
- 目标版本：Android 15（API 35）
- 包名：`cn.autoplay.replacement`
- 项目名称：`playAuto`

## 主要功能

- **USB 连接**：固定使用 Android USB，支持自动发现、权限申请和协议心跳。
- **视频解码**：默认使用系统 MediaCodec 硬解，可切换原版 OpenH264 软解。
  硬解支持 Surface/Texture，软解使用 GLES2，固定请求 25fps、DPI 160。
- **显示设置**：支持分辨率、帧率、DPI、画面比例及显示端横竖屏适配。
- **音频与控制**：支持 PCM 播放、按需麦克风上行、媒体按键和方控学习。
  方控提供默认 Android 按键协议及长安 CS35Plus 厂家广播协议。
- **后台连接**：默认开启，通过前台服务维持连接和音频；返回应用后恢复画面。
- **开机启动**：可选开启，实际启动方式受 Android 版本和厂家限制影响。
- **界面**：默认深色主题，支持浅色及跟随系统；投屏夜间模式默认跟随手机。

设置页“环境检测”左侧显示蓝牙、Wi-Fi 图标，连接时分别点亮。
点击 Wi-Fi 图标查看盒子和手机的简短连接状态。
开机启动及后台连接说明可通过文字旁的圆圈感叹号打开。

高级功能默认隐藏，连续点击软件版本四次解锁，仅当前进程有效。
页面保留 Root 身份检查和 USB 诊断，不提供 Root USB 授权或系统应用转换操作。

## 使用

1. 安装并打开应用，连接受支持的 USB 盒子。
2. 按提示授予 USB 权限；需要通话或语音时授予麦克风权限。
3. 通过盒子连接手机，等待进入 CarPlay。
4. 如需后台连接或开机启动，请在车机系统中允许后台运行并检查自启动、电池及通知设置。

支持的盒子标识：VID `0x1314`，PID `0x1520` / `0x1521`。

## 构建

需要 **Java 17、Android SDK 35、Android Gradle Plugin 8.9.2**。
使用 Android Studio 打开项目，或通过兼容的本机 Gradle 构建。
项目未附带 Gradle Wrapper。

```sh
gradle assembleDebug
```

APK 输出目录：`app/build/outputs/apk/debug/`。
覆盖安装必须使用与已有应用一致的签名。

也可使用手动脚本，脚本会同时运行离线帧测试：

```sh
./build-apk.sh
```

输出：`build/manual/AutoPlayReplacement-debug.apk`。

## 测试

日常修改后仅构建、安装并打开应用，不自动运行功能测试。
仅修改文档时不需要构建。
需要验证连接服务、视频及界面回归时，手动执行：

```sh
sh ./test-connection-service.sh
```

测试脚本依赖手动构建产物，执行前先运行 `./build-apk.sh`。
设备默认 `emulator-5554`，可通过 `ANDROID_SERIAL` 指定，适用 API 28–33。
模拟器测试不能代替真实车机、盒子和手机验证。

## 注意事项

- 当前主要支持 CarPlay，未实现 Android Auto、音频 AEC 或进程死亡后的自动恢复。
- 显示端旋转会更新画布请求，是否即时生效取决于盒子和手机；部分设置可能需要重连。
- Android 10 及以上的开机启动可能使用可点击通知，不保证无人值守启动。
- 后台连接不能抵抗强行停止、进程终止、USB 拔出或车辆断电。
- 原版主投屏解码链路已对齐，但未完整移植厂家专用缩放、仪表屏及可选硬解 OpenGL 后处理。
  Android 4.4 性能及真机花屏恢复仍需实机验证。
- 项目包含原 APK 提取的原生库，发布或再分发前请确认相关授权。
